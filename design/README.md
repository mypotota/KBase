# KBase 设计文档

当前产品优先交付 macOS。正式实现、平台边界与验证结果以根目录 [README](../README.md) 及 `docs/` 为准；本目录保留视觉稿和设计演进，方便继续评审。

## 当前设计约定

- 知识库是用户选择的真实本地根文件夹；项目是子文件夹，文档是 UTF-8 `.md`，Agent 可以直接访问。
- 入口依次为初始化选择/新建知识库、项目列表、项目工作台。新知识库不注入示例文件。
- 工作台采用紧凑黑白界面，只提供浅色和深色；使用官方 shadcn/ui 组件，侧栏可调节。
- 编辑器提供 Markdown 块编辑与源码模式，复杂扩展语法使用源码编辑以保留原文。
- 自动保存与 ⌘S 写回本地，外部修改自动刷新；同时编辑时保留双方版本并显式合并。
- 项目单独开启同步，可仅保留本地；自建 Docker 服务，HTTPS、登录鉴权与历史版本。
- 日志可导出，不记录正文、密码或令牌。Android 在桌面版之后适配。
