# UI 03 · 设计决策

## 信息结构

知识库对应根文件夹，项目对应该根目录中的子文件夹，项目内包含 Markdown 文档与文档子目录。用户首次进入软件时看见初始化页，而非编辑器。

新建或打开知识库后进入项目列表。新知识库显示空状态，引导创建第一个项目。创建项目后仍停留在列表；点击项目进入工作台。新项目内没有示例文档，显示新建文档入口。

评审入口中的示例数据明确与用户新建的知识库分开，仅用于快速检查布局。

## 窗口与布局

桌面评审稿使用最大 1120 × 780 的轻量窗口，15px 窗口圆角与很轻的阴影。背景为中性灰，界面主体白色或深灰。移动端铺满屏幕。

初始化主体宽 410px，两个清楚的文件夹入口纵向排列。项目列表主体最大宽 820px，宽松行距，无仪表板统计卡片。项目名称、描述、文档数构成层级。

工作台不显示活动栏、多标签栏、右侧常驻大纲或底部格式工具栏。顶部保留返回项目、侧栏开关、项目名、同步状态、文档菜单及明暗切换。

左侧文件树默认 222px，可在 185–320px 间拖动或用键盘调整，并在当前浏览器中记住尺寸。正文宽度受限，标题、段落与章节之间留出足够间距。

## 交互

- 已有文件夹和新建知识库使用官方 Dialog；当前原型中明确提示目录选择为模拟。
- 项目使用官方 Button 呈现整行入口，不另写卡片控件。
- 项目搜索实时筛选。无结果时显示空状态。
- 文件树切换文档前保存草稿。点击标题可重命名，正文停止输入 800ms 后保存。
- 输入 `/` 打开官方 Command 菜单，支持基础段落、标题、列表、引用和代码。
- Ctrl/Cmd + K 打开项目文档查找；Ctrl/Cmd + S 立即保存。
- 文档菜单提供阅读模式、源码、大纲、导出、偏好设置与诊断日志。
- 同步、大纲、日志、设置使用官方 Sheet，处理冲突与源码使用官方 Dialog。
- Android 的文件树使用官方 Sheet；选中文档后收起。返回按钮回到项目列表。

## 外观与动效

主题只包含浅色和深色；主色、次要背景、焦点环与状态均为中性灰阶。项目图标允许少量颜色。没有渐变、彩色主题切换或大色块背景。

控件保留官方 shadcn/ui / Radix 的交互模型和键盘焦点行为。悬停使用轻微灰阶变化；Sheet 进入和退出约 200ms，遮罩约 150ms；不为每次输入或保存制造位移动画。遵循系统减少动态效果偏好。
