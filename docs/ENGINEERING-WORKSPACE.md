# 工程工作台

工程现在提供“工程概览”和“资料工作区”两个入口。概览用于恢复目标与下一步，资料工作区保留现有编辑、分屏及同步能力。

## 工程信息

在工程概览中点击“建立工程概览”，会在对应项目文件夹创建 `工程概览.md`，包含“目标”“当前阶段”“下一步”“关键资料”四个二级标题。点击“编辑工程概览”即可维护。外部编辑器和 Agent 可以直接编辑这份普通 Markdown 文件；回到概览时重新读取。

已有同名文件不会被初始化覆盖。建立概览使用统一文件适配器、预期哈希检查和历史备份。切换到概览前先保存当前文档，保存失败时保留工作区。

本轮仍通过知识库的一级目录发现工程；工程身份的独立注册、跨目录资料集合、任务与里程碑尚未实现。根目录“未归档”继续使用原资料界面。

## 动效

安装 `@animate-ui/react` 和 `motion`，工程概览主操作使用 Animate UI Button 原语；现有 shadcn 按钮样式复用。卡片入场尊重系统的减少动态效果偏好。

## 验证

`npm test --prefix web`、`npm run build`。`web/e2e/engineering.spec.ts` 验证建立工程概览、真实文件内容和工作区往返。
